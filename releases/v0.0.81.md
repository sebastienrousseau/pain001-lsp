# pain001-lsp v0.0.81

## Highlights ⭐️

* **In lockstep with pain001 0.0.81**: requires `pain001 >= 0.0.81, < 1`, the family's release that checks IBANs and BICs on every load and refuses files that mix payment batches.
* **Nothing else changed**: the language server, its features and the VS Code extension are the same as in 0.0.80; only the version and the pain001 floor moved.

## Details

The core functions the language server calls are unchanged in pain001 0.0.81. `poetry.lock` and the hash-pinned requirement sets move pain001 from 0.0.80 to 0.0.81 and nothing else.
