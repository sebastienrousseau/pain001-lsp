# pain001-lsp v0.0.79

## Highlights ⭐️

* **Only payment documents get diagnostics**: the server used to read every JSON file the editor sent as payment records, so `package.json` and `tsconfig.json` showed "'id' is a required property". It now diagnoses a JSON document only when it is an array of records or an object naming a payment field, and clears diagnostics on any other.
* **A file pattern for the VS Code extension**: the new `pain001.filePattern` setting (default `**/*.json`) chooses which JSON files reach the server, for example `**/*.pain.json`.
* **In lockstep with pain001 0.0.79**: requires `pain001 >= 0.0.79, < 1`, and the release page is now written by the release workflow in the suite's shape.
