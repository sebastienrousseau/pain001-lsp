# pain001-lsp v0.0.80

## Highlights ⭐️

* **In lockstep with pain001 0.0.80**: requires `pain001 >= 0.0.80, < 1`, so installing or upgrading pain001-lsp brings in the core's security release.
* **Nothing else changed**: the language server, its features and the VS Code extension are the same as in 0.0.79; only the version and the pain001 floor moved.

## Details

pain001 0.0.80 is a security release of the core's REST API ([GHSA-vv3x-jpvc-w468](https://github.com/sebastienrousseau/pain001/security/advisories/GHSA-vv3x-jpvc-w468)). The language server does not use that API, but the suite ships one version, and raising the floor keeps environments that install pain001-lsp off the affected core releases. `poetry.lock` and the hash-pinned requirement sets move pain001 from 0.0.79 to 0.0.80 and nothing else.
