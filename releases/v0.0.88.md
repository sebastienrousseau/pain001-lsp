# pain001-lsp v0.0.88

## Highlights ⭐️

* **In lockstep with pain001 0.0.88**: the server requires pain001 0.0.88, and diagnostics, completion, hover and the editor commands behave as in 0.0.87. The VS Code extension ships at 0.0.88 with the server, and the README lists all fourteen suite repositories.
* **soupsieve 4.0 in the docs toolchain**: the hash-pinned documentation set requires soupsieve 4.0 or newer, clearing a polynomial-time denial of service in its descendant combinator (GHSA-mmhr-3c5m-f64f). The published package never depended on it.
* **The suite audit covers the SDKs**: Suite Consistency pins the core's ecosystem check at the pain001 0.0.88 release, which audits the Go, Java, Rust, .NET and C++ SDKs with the rest of the family, under the job name "Every family publication agrees".

pyproject.toml, `__version__`, CITATION.cff, the README, ROADMAP.md, the bug-report form's placeholders and the VS Code extension's manifest, lockfile and changelog move to 0.0.88 together.
