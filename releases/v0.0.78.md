# pain001-lsp v0.0.78

## Highlights ⭐️

* **Faces commands**: `pain001.faces.list` names each face and the binding keys it accepts; `pain001.faces.project` projects the editor's pain.001 document into UK Open Banking v4.0.1, Berlin Group NextGenPSD2 v1.3.16 or ISO 20022 element names, with a loss report of every source element not carried.
* **Text, not a URI**: the command takes the document text and goes through pain001's `project_face_text`, which refuses a file path, entity declarations and external references. Refusals come back as `{"error": ...}` payloads.
* **In lockstep with pain001 0.0.78**: requires `pain001 >= 0.0.78, < 1`, and the VS Code extension moves to 0.0.78 with the suite.
