# pain001-lsp v0.0.83

## Highlights ⭐️

* **In lockstep with pain001 0.0.83**: requires `pain001 >= 0.0.83, < 1`, the family's release that adds `pain001 verify-signature` to check XML signatures against the signer's certificate.
* **Nothing else changed**: the language server, its features and the VS Code extension are the same as in 0.0.82; only the version, the pain001 floor, build tools and CI actions moved.

## Details

The core functions the language server calls did not change in pain001 0.0.83. `poetry.lock` and the hash-pinned requirement sets move pain001 from 0.0.82 to 0.0.83; virtualenv, dulwich, anyio and pip move in the build and audit sets, and five CI actions take their latest patch releases.
