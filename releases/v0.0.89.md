# pain001-lsp v0.0.89

## Highlights ⭐️

* **In lockstep with pain001 0.0.89**: the server requires pain001 0.0.89, and diagnostics, completion, hover and the editor commands behave as in 0.0.88. The VS Code extension ships at 0.0.89 with the server.
* **Newer development tools**: ruff 0.17.5, complexipy 9, filelock 4.2.10 and myst-parser 5.2.0 are folded in from Dependabot (#110 to #114). None of them ships with the package.
* **Complexity gate kept under its own ceiling**: complexipy 9 scores cognitive complexity higher than 8 did, so the gate's own comparison function was split in two with the same output, and the baseline of existing offenders stays empty.

## Details

pyproject.toml, `__version__`, CITATION.cff, the README, ROADMAP.md, the bug-report form's placeholders and the VS Code extension's manifest, lockfile and changelog move to 0.0.89 together.
