# pain001-lsp v0.0.90

## Highlights ⭐️

* **In lockstep with pain001 0.0.90**: the server requires pain001 0.0.90, and diagnostics, completion, hover and the editor commands behave as in 0.0.89. The VS Code extension ships at 0.0.90 with the server.
* **Container image on Python 3.15**: both Dockerfile stages move from `python:3.12-slim` to `python:3.15-slim`, pinned by digest (Dependabot #115). The package itself is still tested on Python 3.11 to 3.14.

## Details

pyproject.toml, `__version__`, CITATION.cff, the README, ROADMAP.md, the bug-report form's placeholders and the VS Code extension's manifest, lockfile and changelog move to 0.0.90 together. pain001 0.0.90 keeps 0.0.89's dependency floors, so only pain001 moves in poetry.lock and the hash-pinned requirement sets.
