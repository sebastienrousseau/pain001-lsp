# pain001-lsp v0.0.82

## Highlights ⭐️

* **In lockstep with pain001 0.0.82**: requires `pain001 >= 0.0.82, < 1`, the family's release that adds `pain001 check` for pain.001 and pain.008 files you already have.
* **Nothing else changed**: the language server, its features and the VS Code extension are the same as in 0.0.81; only the version, the pain001 floor and two development tools moved.

## Details

The core functions the language server calls behave the same in pain001 0.0.82 (only their docstring examples changed). `poetry.lock` and the hash-pinned requirement sets move pain001 from 0.0.81 to 0.0.82, and ruff and filelock to their latest patch releases.
